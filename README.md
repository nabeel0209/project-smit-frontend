# Learnix Labs — Frontend

Frontend web application for **Learnix Labs**, a role-based LMS platform for learners and course creators.

## Overview

Learnix Labs allows users to explore courses as learners and manage educational content as creators. The frontend includes the public landing page, authentication pages, user dashboard, and creator dashboard.

## Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* Zustand
* TanStack Query
* React Hook Form
* Yup
* Axios
* Google OAuth

## Current Features

* Responsive landing page
* User signup and login
* Creator signup and login
* Google authentication
* Role-based redirects
* Protected frontend routes
* User dashboard
* Creator dashboard
* Auth state restoration after refresh

## Roles

The app currently supports:

```txt
user    → learner dashboard
creator → creator dashboard
admin   → reserved for future admin panel
```

## Status

This project is actively under development. Current focus is authentication, role-based access, and dashboard foundations.
